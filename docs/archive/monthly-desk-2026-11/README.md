# Archive: the monthly paper desk (2026-11-17 to 2026-11-24)

The first version of Ghostdesk traded a monthly long-short book on an Alpaca **paper** account (no real money).
It was stopped and closed on 2026-11-24 when the project became the research platform (decisions D26, D38).
The code is in git history before the merge of `pivot/research-platform`.

The account record (orders, fills, positions, equity history) is kept outside this repository and is not published,
because it describes a retired paper account. Nothing in the public site or in the docs depends on it.
